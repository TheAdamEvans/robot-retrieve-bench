AUC is macro over queries; penalised scores an abstaining config at chance. CIs: bootstrap over intent groups; n is small — read differences as directional.

5,076 judged intent/window pairs. Recall is against known positives in the judgment pool; judged@50 shows how much of each returned top-50 list has been graded. ORACLE rows use supplied programs; LUNA rows use model-generated programs.

Cached-program replay. Programs were reused from v9-abstain without new API calls. Uncached latency is an estimate: measured replay execution time plus the original measured generation time. Token counts retain the original generation usage. Cached-program latency measures this replay.

Label consistency. A fresh labeller instance, blind to earlier grades, re-graded 80 stratified windows: exact agreement 84%, within one grade 98%, relevant-or-not 90%, Cohen's κ 0.65. Same model family and tools: this measures consistency, not independence.
